Introducció a HTML i CSS

HTML és el llenguatge que utilitzem per estructurar el contingut d'una pàgina web. CSS, en canvi, permet definir-ne l'aparença i l'estil.

En aquest document es mostren diferents elements HTML i diverses regles CSS. L'objectiu és crear una pàgina senzilla que compleixi els requisits de l'exercici.

Què és HTML?

HTML significa HyperText Markup Language i serveix per estructurar els continguts d'una pàgina web mitjançant etiquetes.

Elements HTML

Alguns dels elements més habituals són els títols, els paràgrafs, els enllaços, les imatges i les llistes.

Per obtenir més informació sobre HTML es pot consultar la documentació de MDN Web Docs .

Conclusió

HTML i CSS són dues tecnologies fonamentals per crear pàgines web. HTML proporciona l'estructura i CSS permet controlar la presentació visual.

Amb unes poques regles CSS podem modificar colors, tipus de lletra, marges, vores i moltes altres característiques de la pàgina.
